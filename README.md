# Huddle landing page with single introductory section

![Design preview for the Huddle landing page with single introductory section challenge](./design/desktop-preview.jpg)

Solution to the Frontend Mentor **Huddle landing page with single introductory section** challenge - a responsive landing page built from the provided design.

**Live demo:** https://erfan-revenant.github.io/Huddle-landing-page-with-a-single-introductory-section/

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and media queries
- Bundled webfonts and SVG assets from the challenge starter files

## Run locally

```bash
git clone https://github.com/ErfanBagheri404/Huddle-landing-page-with-a-single-introductory-section.git
cd Huddle-landing-page-with-a-single-introductory-section
```

Open `index.html` in a browser. Nothing to install or compile.
